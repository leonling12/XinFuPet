# 芙莉莲与辛美尔

**双人桌宠 · 版本：0.1.0** · macOS 原生桌面伴侣

本项目是在 macOS 桌面边缘展示芙莉莲与辛美尔的非官方同人桌面伴侣。它由 Swift 与 AppKit 构建，使用透明浮动窗口和完整人物 PNG；不拆分头、躯干、手臂或腿，也不对整个人物做交叉淡化。

## 功能

- 状态栏菜单提供 34 个动作：芙莉莲 13 个、辛美尔 13 个、双人互动 8 个。
- 空闲时会自动活动：芙莉莲和辛美尔各自每 25–60 秒随机触发一次动作；双人互动每 2–4 分钟随机触发一次（默认频率）。
- 单击人物触发对应单人动作，双击触发双人互动；悬停与右键菜单提供快捷入口。拖动任一人物会移动整组桌宠，拖动距离驱动同步步态。
- 右键菜单提供打招呼、共同看书、递花、小魔法、坐下等快捷动作、百分数大小输入，以及隐藏和退出；顶部菜单栏的「桌宠」菜单提供显示、隐藏和退出，也包含间距、动作速度、自主活动频率、置顶、低动态和暂停设置。
- 隐藏后可从状态栏选择“显示桌宠”；应用仍在运行时，再次打开“芙莉莲与辛美尔”也会重新显示桌宠。
- 递花互动使用单朵随手部移动的花。

## 系统要求

- 最低系统：macOS 13。
- v0.1.0 本机验证环境：macOS 15.7.4、Apple Silicon（arm64）。Intel Mac 尚未验证。
- 本项目没有第三方 Swift package 依赖。源码使用 Swift tools 5.10。
- 手拖走路使用四个相位索引循环呈现两种腿部姿态；它不是四种独立步态画面。
- “低动态”目前影响窗口移动和缩放过渡，不会放慢人物动作帧；“自主走动”控制动作结束后的窗口轻移，不关闭手拖步态。F13伸展使用单独的512×704动作画布，四帧维持一致的角色比例。

## 从源码构建

在 macOS 上安装包含 Swift 5.10 或更新版本的 Xcode Command Line Tools，然后在仓库根目录运行：

```sh
./scripts/build-releasebundle.sh
./scripts/verify-releasebundle.sh
```

构建脚本使用 `Resources/` 下的 SHA-256 白名单资源生成 `build/releasebundle/XinFuPet.app`。它不依赖本机交接目录、用户偏好或外部私有路径。

## 下载与首次打开

从 GitHub Releases 下载 `XinFuPet-v0.1.0-macos-arm64.zip`，解压后将 `芙莉莲与辛美尔.app` 移到“应用程序”文件夹并打开。

发布包使用 ad-hoc 签名，没有 Developer ID 签名或公证。如果 macOS 阻止首次打开，请前往“系统设置 → 隐私与安全性”，在安全性区域选择系统提供的“仍要打开 / Open Anyway”。不需要关闭 Gatekeeper 或移除隔离属性。
